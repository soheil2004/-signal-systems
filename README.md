2) حل معادلات تفاضلی (سؤال 7-2) — پیدا کردن h[n] با ورودی دلتا

مثال: معادلهٔ گسسته‌ای به‌صورت بازنمونه‌ای (چند معادله داده شده در تصویر). ما برای هر معادله با x[n]=δ[n]، h[n] را محاسبه می‌کنیم عددی (برای n≥0 تا N).

کد نمونه برای معادلهٔ اول (مثال): .

برای پیدا کردن h[n] (پاسخ به δ) کافی‌ست x[0]=1 و x[n>0]=0 و حل بازگشتی برای y[n]:

# حل عددی برای h[n] با بازه n=0..N
import numpy as np

N = 20
h = np.zeros(N+1)
x = np.zeros(N+1)
x[0] = 1.0  # delta

# معادله: sum_{k=0}^4 k * y[n-k] = 2 x[n]
# برای n از 0 تا N:
for n in range(0, N+1):
    s = 0.0
    # قسمتهایی از y که قبلا محاسبه شده
    for k in range(1,5):   # k=0 term is zero (0*y[n])
        if n-k >= 0:
            s += k * h[n-k]
    # معادله: s + 0*y[n] = 2*x[n]  -> y[n] به صورت زیر (در این مثال y[n] در s نیست، پس):
    # اما اگر y[n] هم در ضریب بیاید باید آن را حل کنیم. در این معادله y[n] ضریب صفر دارد.
    # بنابراین y[n] = 2*x[n] - s  (اگر ضریب y[n] وجود نداشت)
    h[n] = 2*x[n] - s

print("h[n] (n=0..10):", h[:11])

> توجه: برای هر معادلهٔ متفاوت در سؤال، شیوهٔ بازگشتی متفاوت است — اگر معادله شامل y[n] با ضریب غیرصفر باشد، آن را به‌صورت خطی حل می‌کنیم (جابه‌جایی ترم‌ها).

3) کانولوشن تحلیلی (سؤال 11-2)

محاسبهٔ کانولوشن:

g(t)=q e^{c(t-a)}u(t-a),\quad r(t)=e^{c t}u(t)

کد sympy برای محاسبهٔ انتگرال کانولوشن:

import sympy as sp

t, tau, a, c, q = sp.symbols('t tau a c q', real=True)
g = q*sp.exp(c*(tau - a)) * sp.Heaviside(tau - a)   # تابع g(tau)
r = sp.exp(c*(t - tau)) * sp.Heaviside(t - tau)     # r(t-tau) = e^{c(t-tau)}u(t-tau)

conv = sp.integrate(g * r, (tau, -sp.oo, sp.oo))
conv_simpl = sp.simplify(conv)
sp.pprint(conv_simpl)

نتیجهٔ نمادین را sympy چاپ می‌کند. (شکل بسته معمولاً شامل نمایی و Heaviside با شرط t≥a و ...).

\int_0^\infty h(\alpha)R(t-\alpha)\,d\alpha = R(t+h_2),

H(s)R(s) = e^{h_2 s} R(s) \Rightarrow H(s)=e^{h_2 s}
